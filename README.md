# PIIXEL-PLAY 🎬

A visually engaging, dark-themed cinematic website for exploring movies and TV shows. This platform provides distinct interfaces for users to discover entertainment content effortlessly.

## 🚀 Features
* **Dark-Themed UI:** A modern and immersive interface designed for a cinematic experience.
* **Content Filtering:** Easily filter and browse through different movies and TV shows.
* **Favorite Tracking:** Dedicated sections to keep track of your favorite entertainment content.

## 🛠️ Technologies Used
* **Frontend:** HTML, CSS

## ⚙️ How to Run Locally
1. Clone this repository to your local machine.
2. Open the downloaded project folder.
3. Simply double-click the `index.html` file to open it directly in your web browser. No local server is required!
